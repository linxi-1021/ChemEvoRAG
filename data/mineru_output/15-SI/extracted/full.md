# Identification of the slowly oxidizing alcohols

To a 50 mL flask were added $\mathrm { F e } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \bullet } 9 \mathrm { H } _ { 2 } \mathrm { O }$ (0.06 mmol), TEMPO (0.05 mmol), $\mathrm { B i C l } _ { 3 }$ (0.1 mmol), 1a (1.0 mmol), 2 (5.0 mmol), and DCE (3 mL) sequentially under air atmosphere. The reaction was then carried out at $5 0 ~ ^ { \mathrm { o } } \mathrm { C }$ under the atmosphere of $\mathrm { O } _ { 2 }$ from a balloon (about 2.5 L) for 48 h. The resulting mixture was cooled to $0 \mathrm { { } ^ { o } C }$ with an ice-water bath for 10 min, then warmed to rt. $\mathrm { C H } _ { 2 } \mathrm { B r } _ { 2 }$ (35 μL) was added as the internal standard. About 0.1 mL of the resulting mixture was taken and filtrated through a disposable syringe filter (PTFE, 13 mm, 0.45 m) eluted with $\mathrm { C D C l } _ { 3 }$ (0.5 mL), and analyzed via 1H NMR. Then the resulting mixture was collected and filtrated through a short column of silica gel eluted with diethyl ether (3 x 25 mL), concentrated, and analyzed via $^ 1 \mathrm { H }$ NMR with $\mathrm { C H } _ { 2 } \mathrm { B r } _ { 2 }$ $( 3 5 ~ \mu \mathrm { L } )$ as the internal standard. According to the comparison of two 1H NMR spectra, the yields of products that have low boiling point were calculated.

To a flask was added 1,6-hexanediol (2.4879 g, 20.6 mmol, 98% purity).
